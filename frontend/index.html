Настройки

Модель скачивается лениво при первой транскрипции на этом размере.

Движки считают на разных стеках, поэтому устройство у них раздельное. В готовой сборке видеокарту умеет только Whisper (нужен драйвер CUDA 12 и cuDNN 9); GigaAM сам откатится на процессор. Применяется сразу, перезапуск не нужен — модель загрузится на новом устройстве при следующей транскрибации.

Профили обрабатываются по очереди: при ошибке первого пробуется следующий.

Пустое поле = встроенная инструкция. Транскрипт подставляется автоматически.

Параметры по умолчанию для режима «Озвучка». Их можно переопределить перед запуском.
