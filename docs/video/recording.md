# Собрать ролик в Zapis под запись

Показываем готовый проект: сценарий, реальные скриншоты, выбор голоса, раскадровку и готовое видео. Пример «ЭДО · короткий ролик» состоит из трёх сцен: проблема с названиями поставщика, схема решения и предложение продукта.

## Подготовка до записи

1. Выполните PREPARE-VIDEO.cmd, затем START-VIDEO.cmd. Откроется http://127.0.0.1:8001/#video.
2. Нажмите «Загрузить» рядом с коротким примером ЭДО. Предыдущий черновик сохраняется в локальном хранилище браузера, готовые сборки остаются в истории.
3. Прослушайте голоса на одном тексте и выберите подходящий. Для записи без интернета подходит уже загруженный Piper. Для Edge нужен интернет даже после прогрева.
4. Один раз соберите пробный ролик. Это загрузит шрифты, браузерные компоненты и выбранную голосовую модель. Установка моделей и зависимостей в демонстрацию не входит.
5. Проверьте звук на компьютере, масштаб браузера 100%, захват системного звука в программе записи и отсутствие личных данных на экранах. При необходимости включите светлую тему штатно в настройках Zapis.
6. Откройте эту памятку и черновик статьи в соседних вкладках. Не запускайте сервер с --reload во время записи: изменение Python-файла прервёт текущую сборку.

## Ход демонстрации, около 6–8 минут

| Время | Что показать | Что объяснить |
| --- | --- | --- |
| 0:00 | Готовый MP4 из истории | Какой результат получится из исходного проекта |
| 0:30 | Три сцены короткого примера | В начале узнаваемая проблема, затем способ решения и предложение |
| 1:20 | Скриншот в первой сцене | Это реальный экран расширения, источник указан в evidence |
| 2:00 | Правку заголовка и текста диктора | Текст в кадре и произносимый текст редактируются отдельно |
| 2:40 | Две короткие пробы голосов | Сначала оцениваем произношение и интонацию, затем собираем ролик |
| 3:20 | Кнопку «Раскадровка» | Проверяем читаемость и содержание кадров без синтеза речи |
| 4:00 | Схему и revealAt в JSON | Узлы появляются по заданным секундам, подписи остаются обычным текстом |
| 4:40 | «Собрать с голосом», быстрая проба | Показываем стадии озвучки и рендера. Ожидание можно ускорить при монтаже |
| 5:40 | Результат, звук, перемотку | Проверяем MP4, а не только первый кадр |
| 6:20 | «Все сцены», JSON и субтитры | Артефакты остаются в проекте и доступны для следующей сборки |

Фактическое ожидание зависит от компьютера, выбранного голоса и сети. Не обещайте заранее заданное время сборки. Для первой записи достаточно горизонтальной быстрой пробы. Финальный ролик можно затем собрать в 1080p и двух форматах.

## Повторить с исходного примера

Нажмите «Загрузить» у примера ещё раз. Это восстанавливает исходные три сцены в редакторе. История и файлы предыдущих запусков сохраняются. Для отдельного сценария сохраните JSON кнопкой «Сохранить JSON».

Если нужен только терминал, из корня проекта:

```bash
python -m backend.cli video storyboard --example edo-short
python -m backend.cli video render --example edo-short --engine piper --speaker ru_RU-irina-medium --preset recording
```

Скриншоты собственного проекта можно положить в video/public/assets, затем указать относительный путь в image. Через интерфейс файлы загружаются кнопкой «Скриншот» у сцены. Для произношения специальных терминов поправьте narration и снова прослушайте пробу. Готовую запись диктора можно прикрепить как WAV к отдельной сцене.
