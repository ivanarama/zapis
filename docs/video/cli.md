# Командный интерфейс Zapis для видео

Агент готовит сценарий из материалов пользователя, Zapis проверяет его, создаёт речь и собирает видео. Команды доступны без браузера и возвращают JSON. Голоса, обработка звука, очередь и история используются те же, что во вкладке «Видео».

В Windows запускайте zapis.cmd по абсолютному пути или из корня Zapis. Скрипт сохраняет текущую рабочую папку, поэтому относительные пути относятся к папке вызова. В примерах ниже команда запускается из корня Zapis.

```powershell
.\zapis.cmd video doctor
.\zapis.cmd video examples
.\zapis.cmd video schema
.\zapis.cmd video example edo-short --output "D:\Projects\my-video\campaign.json"
.\zapis.cmd video validate "D:\Projects\my-video\campaign.json"
.\zapis.cmd video voices
.\zapis.cmd video preview --text "Проверьте результат до переноса документов." --engine edge --speaker ru-RU-SvetlanaNeural --output "D:\Projects\my-video\voice.wav"
.\zapis.cmd video storyboard "D:\Projects\my-video\campaign.json" --output "D:\Projects\my-video\results"
.\zapis.cmd video render "D:\Projects\my-video\campaign.json" --engine edge --speaker ru-RU-SvetlanaNeural --format all --preset full --output "D:\Projects\my-video\results"
```

Для остальных систем используется Python окружения Zapis:

```bash
python -m backend.cli video doctor
python -m backend.cli video render --example edo-short --engine piper --speaker ru_RU-irina-medium
```

## Сценарий и файлы

По умолчанию image и audio разрешаются относительно папки JSON. Параметр --assets задаёт другой корень. Копируются только файлы, на которые ссылаются сцены. Внешние URL, выход через .. и символические ссылки за пределы корня запрещены. Встроенный шрифт берётся из Zapis.

Пример экспортируется вместе с изображениями. Собственный сценарий можно передать через stdin, указав вместо имени файла дефис и задав --assets. Формальная структура доступна через video schema. Команда video validate дополнительно проверяет уникальность id, тайминги появления, ограничения строк и наличие реальных файлов. Валидация не вызывает TTS, не создаёт задание и не загружает голосовые модели.

Параметры голоса: --engine, --speaker, --no-normalize, --accent, --length-scale. При отсутствии явного выбора используются настройки TTS Zapis. Расстановка ударений применяется только поддерживающим её движком. Для готовой озвучки сцены укажите audio с путём к WAV.

## Долгие задания

```powershell
.\zapis.cmd video render "D:\Projects\my-video\campaign.json" --engine piper --speaker ru_RU-irina-medium --no-wait
.\zapis.cmd video status JOB_ID
.\zapis.cmd video wait JOB_ID --timeout 600 --output "D:\Projects\my-video\results"
.\zapis.cmd video jobs
.\zapis.cmd video artifacts JOB_ID --output "D:\Projects\my-video\results"
```

Команда с --no-wait возвращает ID после проверки и постановки задания в очередь. Задание живёт в сервере Zapis и остаётся после завершения процесса CLI. Если сервер не запущен, CLI запускает его в фоне без окна браузера. Для запрета автозапуска укажите --no-start. Клиент проверяет, что сервер принадлежит той же копии проекта. Чужой или устаревший сервер не завершается автоматически.

По умолчанию render и storyboard ждут результат до 1800 секунд. --timeout меняет только время ожидания, сборка при таймауте продолжает работать. Сохраните error.job_id и используйте wait, не отправляйте новую сборку. --quiet убирает сообщения прогресса, результат JSON сохраняется.

При экспорте создаётся отдельная папка DIR/JOB_ID с подпапками форматов. Повторный экспорт одинаковых файлов допустим. Отличающийся существующий файл вызывает ошибку и не перезаписывается. Команды со сборкой --no-wait не принимают --output, экспорт можно выполнить позднее.

## Ответы и ошибки

В stdout находится один JSON-документ, прогресс и диагностика идут в stderr. Проверяйте код выхода и поле ok. В --help выводится обычная справка.

Успешный ответ:

```json
{
  "schemaVersion": 1,
  "ok": true,
  "command": "video render",
  "result": {
    "id": "идентификатор задания",
    "status": "done",
    "outputs": [{
      "format": "landscape",
      "files": {
        "mp4": "абсолютный путь к video.mp4",
        "manifest": "абсолютный путь к manifest.json",
        "srt": "абсолютный путь к subtitles.srt"
      }
    }]
  }
}
```

Ответ также содержит пути кадров и WAV, ссылки предпросмотра и путь папки задания. При --output блок export перечисляет скопированные файлы с SHA-256.

| Код выхода | Значение |
| --- | --- |
| 0 | Команда выполнена. Для --no-wait это постановка задания, а не готовое видео |
| 2 | Ошибка аргументов, сценария или локального файла |
| 3 | Нет зависимостей, сервер недоступен или ошибка API |
| 4 | Очередь занята или выходной файл конфликтует с существующим |
| 5 | Задание завершилось ошибкой или было прервано |
| 124 | Время ожидания истекло, job_id остаётся в ответе |
| 130 | Ожидание прервано пользователем |

Список голосов не раскрывает ключи. Пробы и рендер с облачными движками обращаются к выбранному провайдеру. Перед массовой сборкой прослушайте одну пробу. Успешная техническая проверка звука не гарантирует удачную интонацию.

## Навык для агента

Переносимый исходник навыка находится в skills/zapis-video. Его можно установить в каталог skills среды Codex. Навык определяет свою рабочую копию по ZAPIS_PROJECT_DIR или локальному references/installation.json с полем project_directory. Сценарии и артефакты при этом остаются в папке нужного продукта.

Пример запроса: «Используй zapis-video, сделай ролик об этой обработке по README и реальным скриншотам. Покажи проблему с типовым обменом, фильтры и предпросмотр. Голос Светлана, горизонтальный и вертикальный варианты».
