# Рендерер видео Zapis

React/Remotion-композиции для вкладки «Видео». Голос создаёт Python-код `backend/marketing/voice.py` через существующую фабрику TTS Zapis. Системная озвучка Windows здесь не используется.

Установка: `npm ci` в этой папке. Запуск всего процесса из корня репозитория описан в основном README. Самостоятельный просмотр композиции: `npm run studio`. В Studio используется пример без синтеза голоса.

`scripts/backend.mjs` получает приватный JSON запроса от Python, проверяет сценарий и запускает рендер. Источники и результаты изолированы в папке отдельного запуска. Параметры процесса передаются списком аргументов без shell.

Оригинальные изображения и их источники: `public/assets/edo/sources.json`. Шрифт Noto Sans распространяется с приложенной OFL. Remotion закреплён в package-lock.json, его условия: https://www.remotion.dev/license.

Проверки: `npm test`. Они проверяют сценарий, границы путей, длительности WAV, субтитры и отказ при тихой аудиодорожке. Проверки оркестрации и API находятся в `tests/test_marketing_video.py` в корне проекта.
